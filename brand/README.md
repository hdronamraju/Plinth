# Plinth brand

Logo and brand guidelines, inspired by 1940s–50s California graphics and pared back to feel current.

## Logo

- **Wordmark:** "Plinth" set in [Yellowtail](https://fonts.google.com/specimen/Yellowtail), Teal on cream, with a swash underline on hero uses.
- **Mark:** `plinth-mark.svg` — a butterfly-roof house on a two-step plinth, in front of an ochre sun.
- **Tagline:** "Permits, handled." in Oswald caps.
- **Variants:** teal on cream (primary), cream on ink (reversed), cream on teal, and a "P" monogram badge for favicons and stamps.
- **Clear space:** the height of the lower plinth slab on every side.
- **Minimum size:** lockup 120 px wide; below that, use the mark or monogram.
- **Don't:** stretch, outline, add shadows, or recolor the script.

## Color

| Name | Hex | Use |
|---|---|---|
| Pool Teal | `#3A6E69` | Wordmark, buttons, links |
| Ochre | `#C8A55E` | Sun, highlights (shapes, or text on Ink only) |
| Night Ink | `#262E33` | Body text, plinth, rules |
| Sage | `#B7CFC4` | Backgrounds, status fills |
| Stucco | `#EDE8DE` / `#F6F3EC` | Ground |

Cream text works on Teal and Ink.

## Type

| Font | Role |
|---|---|
| Yellowtail | Wordmark and one short accent phrase per surface |
| Oswald (500–600, caps, letter-spaced) | Headings, labels, buttons |
| Jost (400–500) | Body and UI, 16 px minimum on screen |

All three are on Google Fonts.
