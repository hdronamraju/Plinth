# Piedmont City Code §17.66.010 Intent

Design review is intended to: promote orderly, attractive, safe and harmonious development;
uphold the aesthetic values of the community; and ensure excellence of architectural design; all
as set forth in the Piedmont Design Standards and Guidelines. (Ord. 769 N.S., 10/2023)
