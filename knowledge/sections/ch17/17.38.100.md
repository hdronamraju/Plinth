# Piedmont City Code §17.38.100 Separate Conveyance

The City shall allow an accessory dwelling unit to be sold or conveyed separately from the
primary residence to a qualified buyer if all of the criteria listed under Government Code Section
65852.26 are met. (Ord. 747 N.S., 02/2020; Ord. 768 N.S., 01/2023)
