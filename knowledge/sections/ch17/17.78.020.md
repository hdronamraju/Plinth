# Piedmont City Code §17.78.020 Application

A person wishing to file an appeal must submit an application, stating the grounds for appeal,
within ten calendar days after the date of the decision. The request must be filed with the City
Clerk by 5:00 p.m., and must be accompanied by the appeal fee.
