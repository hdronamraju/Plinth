# Piedmont City Code §17.06.030 Building permits to conform

The Chief Building Official will not issue a building permit for the construction, alteration, or
establishment of an improvement or use within the city contrary to this chapter. Each application
for a building permit shall state on it the purpose for which the proposed improvement is
intended.
