# Piedmont City Code §8.02.080 2022 California Green Building Standards Code - Amendments

This section amends the 2022 California Green Building Standards Code as adopted in
Section 8.02.010, as set forth below.

A.      Section 301.1.1 – Additions and Alterations: Section 301.1.1 is amended to add
the following after the first sentence: “The mandatory provisions of Section 4.408 shall
apply to a project with a building permit valuation of $50,000 or more. The valuation
shall be determined by the Building Official.” (Ord. 767 N.S., 01/2023)
