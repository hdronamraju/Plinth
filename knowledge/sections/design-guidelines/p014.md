# Piedmont Design Guidelines, Page 2-3 (PDF page 14)

2.01.02 IMPLEMENTATION
Each type of design review permit application has its own unique approval process. The three
diagrams on pages 2-4, 2-5 and 2-6 map each type of permit review process, from initial contact
with the Planning Department to a final approval for construction. These diagrams enable
project applicants, design professionals and the general public to better understand project
review procedures.

2.01.03 LEGEND FOR PROCESS DIAGRAMS
