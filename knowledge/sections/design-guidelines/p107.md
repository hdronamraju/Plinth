  2. Porches: The construction of
     additional porches or the
     reconstruction of an existing porch
     should match any porches which
     were original to the existing
     structure. Particular attention
     should be given to the porch roof,
     columns, balustrades and railings,
     which are usually the most visible
     elements of the porch. New
     elements should be compatible with
     the design of the existing elements.
     For new construction, the building
     elements of a porch should also be
     consistent with the overall building
     style. Elements which are
     inconsistent with the architectural
     style of the building should be                                                             Yes

  3. Decks and Balconies: Deck and balcony additions to existing structures, as well as decks
     and balconies that are part of new structures should be consistent with the architectural
     style of the building to which they are attached.
