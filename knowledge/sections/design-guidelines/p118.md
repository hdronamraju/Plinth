# Piedmont Design Guidelines, Page 4-21 (PDF page 118)

4.03.04 ON-SITE AESTHETIC DESIGN COMPATIBILITY; WINDOWS
        IN NEW CONSTRUCTION

The following guidelines apply to new construction:

DESIGN GUIDELINES:
   1. The size, type, proportion,
      placement, details and materials of
      windows should be compatible with
      the overall building style. Window
      elements that should be addressed
      include the frame, the pattern of the
      lites defined by the muntins, and the
      trim used to surround the frame.
                                                             Yes
   2. Windows should be used to
      modulate the building facade, to
      help diminish its mass and scale.

   3. Windows should be recessed from
      the face of the building wall to
      create a distinct shadow line.

                                                             Yes
