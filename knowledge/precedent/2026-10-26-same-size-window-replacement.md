# Replacing a window with another is allowed if size, location, operation, recess and lite pattern don't change

## Question

Can the windows over the property line be replaced with new double-pane windows if they are the same size, or do we have to keep the old single-pane windows?

## Staff answer (verbatim)

> You could replace the window with another provided that there is no change in the following: The size or location of the window. The operation of the window. The recess of the window measured from exterior wall face to the window sash. The divided lite pattern (if any), provided that any new divided lites are either true divided lites or 3-dimensional simulated divided lites.

## Context

Asked about windows over the property line; the criteria match the city's Window Replacement Policy.
