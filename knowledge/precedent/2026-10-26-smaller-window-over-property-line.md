# A smaller window in an existing opening over the property line is not an in-kind repair

## Question

In-kind repairs are allowed for portions of the building over the property line. Would this allow replacing an existing window with a smaller window within the existing opening?

## Staff answer (verbatim)

> No, this change would not constitute an in-kind repair.
